# Claude Code 开发指令（运势测算 Web App）

你是一名资深全栈工程师 + UI设计师，请基于以下PRD开发一个可直接运行的Web应用。

---

## 一、项目目标

开发一个“运势测算工具”（娱乐性质），支持PC和移动端浏览器访问，具备以下能力：

* 输入出生日期和时间
* 基于当前时间进行运势计算
* 输出：八字、星座、塔罗、综合运势

---

## 二、技术约束（必须遵守）

### 前端

* 使用 Next.js（App Router）
* 使用 Tailwind CSS
* 使用 TypeScript
* 响应式设计（Mobile First）

### 数据与状态

* 不使用数据库
* 不使用用户登录系统
* 不存储用户数据（包括localStorage，除非用于UI状态）

### 运行方式

* 项目可直接 `npm install && npm run dev` 启动

---

## 三、页面结构（必须实现）

### 1. 首页（/）

功能：

* 输入出生日期（Date Picker）
* 输入出生时间（Time Picker）
* 显示当前时间（自动获取）
* 按钮：「开始测算」

交互：

* 点击按钮后跳转 `/result`
* 使用 query params 传递数据（如 ?date=xxx&time=xxx）

---

### 2. 结果页（/result）

必须包含以下模块（卡片式布局）：

#### （1）八字模块

* 显示四柱（年/月/日/时）
* 五行分布（可用进度条或图形表示）
* 简要文字解读

#### （2）星座模块

* 自动计算星座
* 展示：

  * 今日运势
  * 爱情 / 事业 / 财运

#### （3）塔罗模块

* 随机抽取1~3张牌
* 每张牌包含：

  * 名称
  * 正位/逆位
  * 含义
* 必须包含“翻牌动画”

#### （4）综合运势模块

* 输出一个 0~100 的评分
* 用进度条或仪表盘展示
* 输出总结性描述

#### （5）建议模块

* 今日建议
* 桃花运
* 幸运数字（1~9）
* 幸运颜色

---

## 四、核心函数（必须实现）

请实现以下函数，并单独放在 `/lib` 目录：

* `calculateBazi(date, time)`
* `getZodiac(date)`
* `drawTarot()`

要求：

* 逻辑清晰
